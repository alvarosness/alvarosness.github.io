Having knowledge is necessary for long term learning for without knowledge, you don't have the foundation for the higher level skills of analysis, synthesis, and creative problem solving.

> [!quote] One cannot apply what one knows in a practical manner if one does not know anything to apply.

Mastery requires both the possession of ready knowledge ad the conceptual understanding of how to use it.

> Because learning is based on prior knowledge, the more we learn, the more possible connections we create for learning, i.e. the more we learn the more are able to learn.
